# xfoxx.com

![Cover image based on website hero](https://github.com/marcusbillman/xfoxx.com/blob/main/public/social-embed.jpg?raw=true)

Website for my music project xfoxx, hosted at [xfoxx.com](https://xfoxx.com). It features a list of releases, links to streaming platforms, and some bio content.

The website is fully designed and built by me.

## Built with

These are some of the technologies powering the site:

- 🧑‍🚀 [Astro](https://astro.build/) for the web framework
- ⚛️ [React](https://react.dev/) for the UI framework
- 🧠 [Tailwind CSS](https://tailwindcss.com/) for styling
- ▲ [Vercel](https://vercel.com/) for hosting
